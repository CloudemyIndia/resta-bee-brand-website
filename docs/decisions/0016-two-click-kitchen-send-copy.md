# 0016: State the two-click kitchen send benefit

## Context

The user asked the homepage to explain the speed of sending an order to the kitchen, specifying that it takes two clicks.

## Decision

Use the kitchen feature heading: “Two clicks. Order sent to the kitchen.” Keep the supporting paragraph focused on preparation stations and ticket progress.

## Rejected

- Vague speed language that omits the two-click detail.
- An unrelated proof badge or speed statistic without the specific workflow context.

## Consequences

The kitchen feature leads with the user-approved two-click send claim. Product behavior remains subject to product implementation; this copy records the user's stated workflow.
