# 0023: Add device bezels to homepage UI screenshots

Date: 2026-11-03

## Context

Several supplied POS screenshots appeared as unframed images beside other homepage screens already shown inside phone or computer frames.

## Decision

Add dark screen bezels to the floor, kitchen, central-menu and menu-preference screenshots. On phone widths, frame the portrait screenshots as phones and keep them at their uncropped aspect ratios. Preserve the existing My Shift, Reports and multi-device frames.

## Rejected

- Showing product UI screenshots as bare images beside framed device screens.
- Cropping supplied screenshots to fill device shapes.

## Consequences

Product screenshots have a consistent device treatment across the homepage while preserving all supplied interface content and responsive image choices.
